# 골든타임 · 병기 판정

초기 설정의 **뇌졸중 진단일**로 경과일을 계산해 병기를 정한다. 발병 후 180일 이내 집중 재활이 회복률을 결정한다는 신경가소성 이론 기반 ([[theories]]).

```python
days = (today - stroke_date).days
stage = "급성기" if days <= 30 else "아급성기" if days <= 90 else "만성기" if days <= 180 else "유지기"
```

| 병기 | 경과일 | D-day 배지 | 권장 훈련 | 재평가 |
|------|--------|-----------|----------|--------|
| 급성기 | 0~30 | 빨강 | 매일 30~40분 | 2주 |
| 아급성기 | 31~90 | 주황 | 매일 40~50분 | 4주 |
| 만성기 | 91~180 | 회색 | 주 5회 30~40분 | 8주 |
| 유지기 | 180+ | 회색 | 주 3회 이상 | 12주 |

- D-day: 180일 카운트다운, 홈 상단 배지 ([[screens]])
- 재평가 = [[severity-assessment]] 재실시. 미니 평가는 병기와 무관하게 매 세션.
