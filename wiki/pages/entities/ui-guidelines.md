# UI/UX 규칙 (50+ 사용자)

| 항목 | 규칙 |
|------|------|
| 최소 폰트 | 14px (`--fs-xs`) |
| 본문 폰트 | 18px (`--fs-md`) |
| 터치 타겟 | 최소 60px |
| 화면 구성 | 한 화면 = 한 목적 |
| 대비 | WCAG AA 이상 |
