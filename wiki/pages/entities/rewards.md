# 스탬프 · 가족 공유

"속도보다 반복" 원칙([[overview]])을 지키기 위한 지속 동기 장치. 자기효능감·행동활성화 이론 기반 ([[theories]]).

## 스탬프

세션 완료 시 한국 명소 스탬프 1개 (10개 순환, `stampIn` 애니메이션):
경복궁 · 남산타워 · 해운대 · 한라산 · 제주도 · 담양 죽녹원 · 설악산 · 불국사 · 진해 벚꽃길 · 안동 하회마을

## 카카오톡 가족 공유

결과 화면 하단 노란 버튼 "오늘 훈련 결과를 가족에게 보내기". 내용: 완료 운동 수, 레벨 변동, 스탬프.
카카오톡 공유 API 연동은 **미구현**.

데이터 저장: Session.stampId → [[data-model]]
