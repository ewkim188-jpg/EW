# 16가지 운동 (4대 영역)

실행 흐름: **Phase A** 영상 시청 → **Phase B / B-read / C** 과제 → "다음으로" → [[level-system]] 체크 → 다음 운동

| 타입 | Phase |
|------|-------|
| `t:'self'` 자가확인 | C (체크리스트) |
| `t:'auto'` + `READ_EX` | B-read (읽기 과제) |
| `t:'auto'` 그 외 | B (녹음 + 자동 측정) |

## 읽기 과제 (Phase B-read)

```javascript
const READ_EX = { 10:'pair', 13:'tap', 14:'slow', 15:'loud', 11:'stress' };
```

| 서브타입 | 화면 |
|---------|------|
| slow | 문장 카드 + 음절 하이라이트 |
| loud | 문장 카드 + dB 미터 |
| pair | 최소대립쌍 카드 2개 |
| tap | 비트 박자 + 문장 |
| stress | 강조 단어 하이라이트 |
